MASTER PAVING CONSTRUCTION WEBSITE
=================================

FILES
- index.html       Homepage
- about.html       About the company
- contact.html     Contact details and WhatsApp quotation form
- styles.css       Responsive styling, animations and 3D hover effects
- script.js        Mobile navigation, reveal animation, tilt effects and WhatsApp actions
- assets/          Supplied company logo and project photographs

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html (or right-click > Open with > Chrome).
4. Keep the assets folder beside the HTML files. Do not move the HTML files away from it.
